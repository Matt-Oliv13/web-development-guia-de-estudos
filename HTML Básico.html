POST 3: Conteúdo Complementar com Aside

A tag 'aside' é usada para inserir um conteúdo complementar ao conteúdo principal da página. Ela pode aparecer como uma observação, uma dica, um aviso, uma curiosidade ou até uma área com links relacionados.

Sozinha, a tag 'aside' não posiciona automaticamente o conteúdo na lateral da página. Para criar esse efeito visual, usamos CSS. Neste exemplo, a organização em duas colunas foi feita com display flex.

Assim, o conteúdo principal fica à esquerda, enquanto o bloco complementar aparece destacado na direita, funcionando como uma caixa lateral de apoio ao assunto.

Observação lateral

Este bloco foi criado com a tag 'aside'. Em uma página real, ele poderia trazer uma explicação extra, um resumo rápido ou uma dica relacionada ao conteúdo principal.

POST 12: Tabelas

Para tabelas, usaremos os comandos 'table' com parâmetro de borda (border=""), e definiremos, assim como no resto do código, thead, tbody e tfoot. Em cada secção da tabela, deverão ser inseridas as rows com 'tr' seguidas das colunas 'th' ou 'td' (sendo a primeira em negrito). os comandos rowspan="" e colspan="" irão permitir a mesclagem do número de linhas ou colunas desejados.

Pontuação Avaliação
0-4 Reprovado
5-6 Em Recuperação
7-10 Aprovado
No caso de reprovação, o aluno deverá pagar uma taxa para poder cursar a matéria novamente

POST 13: Formulário de Feedback

Aqui criaremos um formulário, unindo vários dos conhecimentos anteriores, para permitir um usuário a realizar um feedback. Perceba no código que o input virá após o label, tendo em vista que dessa vez teremos que informar o que será digitado pelo usuário

Informações de contato








Neste formulário, utilizamos 'fieldset' para definir uma área que englobasse todos os campos, 'legend' para inserir informações junto à linha de borda (informações de contato), 'textarea' ao invés de 'input type' na área de comentários para dar mais espaço ao usuário, e 'button' para criar um botão de envio.

OBS: o parâmetro 'onclick="alert('Feedback enviado') presente no comando do botão faz parte de uma funcionalidade integrada ao JavaScript, que não é o foco agora.

POST 14: Caracteres Especiais e Links

Para digitar um caracter especial no código html, pode-se usar uma combinação de '&'+ determinadas letras e ";". Exemplo: para o símbolo de "<" usaremos '&' + 'lt;' para o ">" usaremos '&'+ 'gt;'. para copyright use '&'+ 'copy;'
