**Sobre JavaScript**

JavaScript é uma linguagem de programação muito utilizada para tornar páginas web mais interativas. Enquanto o HTML organiza a estrutura da página e o CSS cuida da aparência, o JavaScript permite criar comportamentos, respostas a cliques, alterações de conteúdo, validações, animações e outras ações dinâmicas. Trata-se de uma linguagem interpretada, ou seja, o código é lido e executado por um interpretador. No caso das páginas web, esse interpretador já existe dentro do próprio navegador. Assim, quando acessamos uma página com JavaScript, o navegador consegue executar os scripts diretamente no computador do usuário.

IMPORTANTE!
Estabeleça como prática padrão da web: utilizar HTML para a estruturação de conteúdo. Ao formatar, utilize CSS e comportamento com JavaScript.

**Hospedagens**
Um navegador web é um exemplo de ambiente de hospedagem ECMAScript funcionando do lado do cliente. Isso significa que ele oferece recursos para que o JavaScript seja executado durante a navegação. Apesar disso, JavaScript não está limitado apenas aos navegadores. Ele também pode ser usado do lado do servidor com Node.js, que é um ambiente de execução instalado no sistema operacional do computador, como macOS, Windows ou Linux. Com Node.js, é possível criar programas em JavaScript fora do navegador, inclusive aplicações capazes de funcionar como servidores.

Trabalharemos com:

• Variáveis: espaço nomeado para armazenar um dado que pode mudar durante a execução do algoritmo. 
Ex: preco, nivel, quantidade

• Constantes: valor que deve permanecer o mesmo ao longo do código. Ex: o valor de π

Em JavaScript, é uma boa prática declarar variáveis antes de utilizá-las. Os nomes das variáveis podem usar letras maiúsculas e minúsculas, números, sublinhados e cifrões, mas não podem começar com números. Também não devemos usar palavras reservadas da linguagem como nomes de variáveis.

    "abstract arguments await boolean break byte case catch char class const continue debugger default delete do double else enum eval export extends false final finally float for function goto implements if import in instanceof int interface let long native new null package private protected public return short static super switch synchronized this throw throws transient true try typeof var void volatile while with yield"

IMPORTANTE! 
O interpretador JavaScript diferencia maiúsculas de minúsculas (CASE SENSITIVE) em nomes de variáveis. Então nomes como total, Total ou TOTAL serão tratados como variáveis diferentes.

LET/VAR
• Para declarar variáveis que poderão mudar de valor durante o programa, usamos let. Essa é a forma mais recomendada para variáveis comuns, pois evita redeclarações dentro do mesmo escopo. Também existe var, que é uma forma mais antiga e mais flexível, mas pode causar confusão em códigos maiores;

CONST
• Para declarar valores que não devem ser reatribuídos ao longo do código, usamos const.

Para declarações, como outras instruções JavaScript, podemos terminar com um ponto e vírgula (;). Embora nem sempre ele seja obrigatório, usá-lo ajuda a deixar o código mais claro e reduz o risco de interpretações indesejadas.

IMPORTANTE!
Antes de fazer a declaração de variáveis, recomenda-se utilizar a expressão "use strict"; (com as aspas + ponto e vírgula) para ativar um modo mais rígido de interpretação do JavaScript. Com isso, o código passa a seguir regras mais seguras, como impedir o uso de variáveis não declaradas.

Quando definimos uma variável ou constante fora de um bloco de código definido por chaves {}, ela fica disponível em um escopo mais amplo. Quando declaramos uma variável com let ou const dentro de um bloco, ela só pode ser acessada dentro daquele bloco.

Ex:
    let curso = "JavaScript";
    {
    let modulo = "Introdução";
    console.log(curso);
    console.log(modulo);
    }
    console.log(curso);
    console.log(modulo);

No exemplo acima, temos o retorno:
    JavaScript
    Introdução
    JavaScript
    Erro: modulo não está definido fora do bloco

Pois modulo é uma variável local, disponível apenas dentro do escopo entre {}.

TIPOS DE DADOS
Dados literais primitivos
Existem sete tipos de dados primitivos: boolean, number, BigInt, string, symbol, undefined e null.

• Boleano (boolean): representa um valor lógico. Só pode receber true ou false, sempre em letras minúsculas.
• Numéricos (number): representam números inteiros e decimais. 
• BigInt: usado para representar números inteiros muito grandes. Para criar um valor BigInt, adicionamos a letra n ao final do número.
• String: representa uma sequência de caracteres, ou seja, textos. Pode ser escrita com aspas duplas (“ “), aspas simples (‘ ‘) ou crases (` `). 
• Symbol: representa um valor único e imutável, usado principalmente em situações mais específicas com objetos.
• Null: representa uma ausência intencional de valor.
• Undefined: indica que uma variável foi criada, mas ainda não recebeu um valor.

Exemplo:
Em caso de utilizarmos a operação soma (+) com strings, ocorrerá uma concatenação (a seguir usaremos o operador typeof que retorna o tipo de dado analisado)
    let codigo = "20" + "25"; 
    console.log(codigo); // -> 2025 
    console.log(typeof codigo); // -> string


O console.log funciona de forma parecida com um print, exibindo informações no console. Também podemos usar crases para montar textos com variáveis e expressões dentro deles. Para isso, usamos o símbolo $ junto com { }. Exemplo:

    let preco=30; 
    let desconto=5; 
    console.log (`O valor final é ${preco-desconto} `);
    // O valor final é 25

Atenção!
Ao utilizarmos strings, precisamos conhecer novos conceitos: métodos e autoboxing. Um método é uma função associada a um objeto. Objetos são estruturas mais complexas, que podem armazenar propriedades e métodos. Para chamar um método, escrevemos o nome do objeto ou valor, colocamos um ponto (.) e depois o nome do método. Um exemplo é console.log, em que console é o objeto e log é o método utilizado para exibir informações.

Os dados primitivos possuem objetos correspondentes que podem ser usados temporariamente pelo JavaScript. Esse comportamento é chamado de autoboxing. Quando acessamos uma propriedade ou método a partir de um valor primitivo, o interpretador cria uma conversão temporária para permitir esse acesso.

Exemplo:
    let palavra = "Cadastro";
    let exibir_caracter = palavra.charAt(3);
    console.log(exibir_caracter);
    exibe -> a (o quarto caractere de 'Cadastro', posição [3])
    Usamos o método charAt(), que retorna uma única letra da posição indicada. A contagem das posições começa em zero.


MÉTODOS COMUMENTE UTILIZADOS:
• length: propriedade que informa o número de caracteres de uma string. 
    Ex:
    let str = "Curso JS";  
    str.length
    // -> 8

• charAt(index): informa o caractere localizado na posição “index” da string (começam com zero). 
    Ex:
    let str = "Curso JS";
    str.charAt(6)
    // -> J

• slice(beginIndex, [opcional] endIndex): método que retorna uma nova string formada a partir dos caracteres entre beginIndex (incluído) e endIndex (excluído); se endIndex for omitido, a nova string será formada de beginIndex até o final dela.    
    Ex:
    let str1 = "estudando javascript";
    str1.slice(0,9) -> “estudando”
    str1.slice(10,20) -> “javascript”

• split(separator, [opcional] limit): divide a string em partes sempre que encontra um separador e retorna um array com essas partes. O parâmetro opcional limit limita a quantidade de partes adicionadas ao array.
    Ex1:
    let str1 = "html css javascript";
    str1.split(" ") -> “html”, “css”, “javascript”
    Ex2:
    console.log('10/06/2026'.split('/'));
    // ['10', '06', '2026']

Conversão de strings com parse em JavaScript

Em JavaScript, algumas informações digitadas pelo usuário em formulários chegam como string, mesmo quando parecem números. Para transformar essas strings em valores numéricos, podemos usar funções de conversão como parseInt() e parseFloat().

O parseInt() converte uma string para um número inteiro:

    let idade = "25";
    let idadeConvertida = parseInt(idade);
    console.log(idadeConvertida); // 25

Já o parseFloat() converte uma string para um número decimal:

    let preco = "19.90";
    let precoConvertido = parseFloat(preco);
    console.log(precoConvertido); // 19.9

Essas funções leem a string da esquerda para a direita e tentam extrair um número válido. Por exemplo:

    console.log(parseInt("20 anos")); // 20
    console.log(parseFloat("10.5 reais")); // 10.5

Mas, se a string não começar com um número válido, o resultado será NaN, que significa Not a Number:

    console.log(parseInt("idade 20")); // NaN

Também existe o Number(), que converte a string inteira para número, mas é mais rígido:

    console.log(Number("20"));       // 20
    console.log(Number("20 anos"));  // NaN

Resumo: usamos parseInt() para números inteiros, parseFloat() para números decimais e Number() quando queremos converter uma string que contém apenas um número válido.

POSSIBILIDADES DE INTERAÇÃO COM O USUÁRIO:
OBS: Necessário inserir no código HTML

a) Caixa de alerta: usamos o método alert(), que recebe um texto como parâmetro e exibe uma mensagem para o usuário. Também podemos escrever window.alert().

ESTRUTURAS DE CONTROLE DE FLUXO

1) CONDICIONAIS:

if(condição) { //bloco de código a ser executado se a condição for verdadeira }

if (condição) { condição - código verdadeiro }
else { condição - código falso }

if (condição_1) { codigo }
else if (condição_2) { codigo }
else if (condição_3) { codigo }
else { codigo }

switch (expressão) {
    case resultado 1:
        código 1
        break;
    case resultado 2:
        código 2
        break;
    default:
        código
}
// A declaração switch permite comparar o valor de uma expressão com diferentes casos possíveis. Quando encontra uma correspondência, executa o bloco indicado. O break evita que os próximos casos sejam executados sem necessidade.

Ex: 
let turno = prompt("Qual seu turno? ");
switch(turno){ 
    case "manhã": 
        alert("Você estuda pela manhã");
        break;
    case "tarde": 
        alert("Você estuda à tarde");
        break; 
    case "noite": 
        alert("Você estuda à noite"); 
        break; 
    default: 
        alert("Turno não reconhecido");
}


2) LAÇOS DE REPETIÇÃO:

2.1 Laço for
Usamos for quando temos uma noção clara de quantas vezes o bloco deve se repetir. Por exemplo, quando queremos contar de 1 até 5 ou percorrer uma quantidade definida de elementos.


A sintaxe é: 
for (inicialização; condição; incremento) { bloco de código a ser executado }

Ex: 
for (let i = 1; i <= 5; i++) { 
    console.log(i); 
    }
// inicializamos a variável i com 1, definimos a condição (i<=5) e aumentamos 1 a cada repetição (i++).


2.2 Laço While
Normalmente usamos quando não sabemos exatamente quantas vezes repetir algo, mas sabemos qual condição precisa continuar verdadeira para o laço seguir.


A sintaxe é:
while(condição) { bloco de código }

Ex: se desejarmos imprimir os números de 5 em 5 até 25: 
let num = 5; 
while(num <= 25) { 
    console.log(num); 
    num += 5; 
    }


2.3 Laço do/While
É parecido com o loop while, mas possui uma diferença importante: no while a condição é testada antes da execução do bloco, enquanto no do/while o bloco executa pelo menos uma vez antes da verificação.

A sintaxe é: 
do {
    bloco de código
} while(condição);

Reescrevendo o último exemplo:
let num = 5; 
do { 
    console.log(num); 
    num += 5; 
} while(num<=25)
