Olá!

Este repositório reúne meus materiais de estudo sobre desenvolvimento web, combinando anotações teóricas, exemplos práticos e pequenos exercícios para consulta e revisão.

O conteúdo está sendo construído gradualmente, começando por HTML e CSS, com a adição posterior de materiais sobre JavaScript. A proposta é registrar minha evolução nos estudos, organizar conceitos importantes e manter um guia prático para reforçar o aprendizado.

Alguns conteúdos foram desenvolvidos a partir de aulas, pesquisas e práticas próprias, sendo reescritos e adaptados com minhas anotações, exemplos e observações pessoais.
